# 現調ノート 配布用一式

このフォルダの中身を、そのままWebに置いてください。中身は4つだけです。

    index.html              アプリ本体（単価は入っていません）
    manifest.webmanifest    ホーム画面に追加したときの見え方
    sw.js                   圏外でも開けるようにする仕掛け
    icon.svg                アイコン

## なぜ Artifact ではだめか

Claudeのアカウントが要ります。従業員は持っていません。
画面の上にもClaudeの枠が出ます。現場で使う道具の見た目ではありません。

## どこに置くか

自前のURLであれば、どこでも構いません。大事なのは3つです。

1. **https であること** — マイクもカメラも、httpsでないと動きません
2. **枠の中に入れないこと** — iframeに包むと、マイクが使えなくなります
3. **フォルダごと置くこと** — sw.js が同じ場所にないと、圏外で開けません

## 置いたあと、営業に伝えること

    1. 送られたURLを Safari で開く
    2. 下の共有ボタン（□に↑）を押す
    3. 「ホーム画面に追加」を押す

これでアイコンが並び、アドレスバーのない画面で開きます。
一度開いておけば、電波がなくても開きます。
